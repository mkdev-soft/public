# Privacy Policy for PopsIt / Política de Privacidad de PopsIt

**Last updated / Última actualización:** November 11, 2026 / 11 de noviembre de 2026

---

## 🇬🇧 Privacy Policy (English)

### 1. Overview
PopsIt is a browser extension designed to let users create, customize, move, and download floating sticky notes on web pages. We respect your privacy and are committed to protecting it.

### 2. Data Collection and Usage
PopsIt **does not collect, store, transmit, or sell any personal data**, browsing history, or user activity.
* **Note Content:** All text written inside the sticky notes remains strictly local within your browser's active session memory. When you choose to download a note, the file is generated locally on your device without passing through any external server.
* **No Analytics or Tracking:** We do not use cookies, third-party analytics, or tracking scripts of any kind.

### 3. Browser Permissions
To function properly, PopsIt requires specific browser permissions, which are used exclusively for the core features of the extension:
* **`activeTab` & `scripting`:** Used solely to inject the sticky note interface (HTML/CSS/JS) into the currently active webpage when triggered by the user.
* **Host Permissions (`<all_urls>`):** Required so the extension can render floating notes on any website the user chooses to browse. PopsIt does not read, scrape, or modify the underlying content or data of the websites you visit.

### 4. Third-Party Services
PopsIt operates entirely offline within your browser using locally bundled libraries. No data is shared with third parties.

### 5. Changes to This Policy
If future updates introduce new features (such as cloud synchronization), this Privacy Policy will be updated accordingly before any changes take effect.

### 6. Contact
If you have any questions or concerns about this Privacy Policy, you can contact the developer by opening an issue in this GitHub repository or through the **Support** tab on the extension's Chrome Web Store listing.

## 🇪🇸 Política de Privacidad (Español)

### 1. Resumen
PopsIt es una extensión de navegador diseñada para permitir a los usuarios crear, personalizar, mover y descargar notas adhesivas flotantes sobre páginas web. Respetamos tu privacidad y nos comprometemos a protegerla.

### 2. Recopilación y Uso de Datos
PopsIt **no recopila, almacena, transmite ni vende ningún dato personal**, historial de navegación ni actividad del usuario.
* **Contenido de las notas:** Todo el texto escrito dentro de las notas adhesivas permanece de forma estrictamente local en la memoria de la sesión activa de tu navegador. Cuando decides descargar una nota, el archivo se genera localmente en tu dispositivo sin pasar por ningún servidor externo.
* **Sin analíticas ni rastreo:** No utilizamos cookies, herramientas de análisis de terceros ni scripts de seguimiento de ningún tipo.

### 3. Permisos del Navegador
Para funcionar correctamente, PopsIt requiere permisos específicos del navegador que se utilizan exclusivamente para las funciones principales de la extensión:
* **`activeTab` y `scripting`:** Se utilizan únicamente para inyectar la interfaz de la nota adhesiva (HTML/CSS/JS) en la pestaña activa actual cuando el usuario lo solicita.
* **Permisos de Host (`<all_urls>`):** Son necesarios para que la extensión pueda mostrar notas flotantes en cualquier sitio web que el usuario visite. PopsIt no lee, extrae ni altera los datos o el contenido propio de las páginas web que visitas.

### 4. Servicios de Terceros
PopsIt funciona completamente en local dentro de tu navegador utilizando librerías empaquetadas en la propia extensión. Ningún dato se comparte con terceros.

### 5. Cambios en esta Política
Si futuras actualizaciones incorporan nuevas funciones (como sincronización en la nube), esta Política de Privacidad se actualizará oportunamente antes de que los cambios entren en vigor.

### 6. Contacto
Si tienes alguna pregunta o duda sobre esta Política de Privacidad, puedes contactar con el desarrollador abriendo una incidencia (*Issue*) en este repositorio de GitHub o a través de la pestaña de **Asistencia / Soporte** en la ficha de la extensión dentro de la Chrome Web Store.
